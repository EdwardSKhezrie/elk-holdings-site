# ELK Holdings website

Website and partner portal for ELK Holdings (Eddie Khezrie, Founder & CEO). Static site, no build server.
Hosted on GitHub Pages from the `main` branch: https://edwardskhezrie.github.io/elk-holdings-site/ (redeploys about a minute after each push).
It is also installable as an app (manifest.webmanifest + sw.js): iPhone Safari "Add to Home Screen", desktop Chrome/Edge "Install app".

## Files
- `index.html` — the whole site on one link: public views (home, investments, 7 category pages, portfolio, leadership, contact) plus the partner login (`#login`) and portal. Navigation is hash-based. Generated by `tools/build_portal.py`; rebuild from the private source rather than hand-editing the portal parts.
- `portal/vault/<sha256("elk:"+login)>.json` — each partner's data, encrypted with that partner's code (PBKDF2-SHA256 250k + AES-256-GCM). The page decrypts it in the browser after login. `index.html` itself contains NO partner data.
- `portal/index.html` — redirect to `../#login` for old links.
- `prices.json` — latest public closing prices for the portal's tickers (no amounts). Updated daily by a scheduled task.
- `tools/build_portal.py` — rebuilds `index.html` and the vault files. Private source of truth: Eddie's private Claude artifact https://claude.ai/artifact/1yA1bmJH2y3z2rCtbUggGa (read with the Artifact tool). Partner codes are held by Eddie only; ask him for them to re-encrypt. Never commit codes or plaintext partner data.
- `crest*.jpg`, `icon-*.png`, `apple-touch-icon.png` — ELK crest images and app icons.

## Brand
Black (#000) background, gold accents (#C9A45C / #E8CB8A). Fonts: Cinzel (marks/labels), Cormorant Garamond (headings), Figtree (body). Plain, simple wording. Do not mention Jimmy Jazz. ELK is a family office; every category is core (not real-estate-first).

## Content rules
- Public pages never show specific deals, amounts or the healthcare deal under review. The Portfolio page is intentionally private ("Partner access required").
- Never put partner names, amounts, deal details or login codes in a plaintext public file.
- Tickers on category pages are examples of public companies, labeled as not recommendations or ELK holdings.
- Never add made-up holdings, deal counts or track record to public pages.
